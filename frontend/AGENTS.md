## UI copy preference

Do not add explanatory subtitles, grey helper paragraphs, feature descriptions,
or redundant usage tips to the UI. Keep copy minimal: headings, control labels,
account/order data, concise empty/loading states, validation errors, action
results, and required attribution. Put necessary input instructions in labels
or placeholders rather than separate helper paragraphs.
